Posting Shortcuts

Save a server channel and a text template. Each Send template tap sends one message to that saved channel. Cards show the last confirmed template send and slowmode availability. Use Change all templates to update every saved shortcut for the current account at once.

Paste this folder URL into Revenge's plugin installer:

https://xjetmaker.github.io/revenge-plugins/posting-shortcuts/

After enabling, open plugin settings or use /postingshortcuts, then choose Add shortcut. Test with a harmless template in one permitted channel first.

Optional: enable Replace my last message in a shortcut’s Edit form. The latest own message is captured before posting and deleted only after the new message is confirmed. Failed sends retain the old message; deletion errors require review and never resend.

Cooldown expiry does not send automatically. Unconfirmed attempts stay locked for review. No broadcast or automatic repeat. No guarantee against account restrictions.

Version 0.1.3 · Target: classic Revenge 1.11.6 / Discord Android 347.12. Phone compatibility needs verification.
